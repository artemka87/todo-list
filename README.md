# 📋 To-Do List

Красивый и удобный веб-сайт для управления списком задач. Всё работает локально в браузере с автоматическим сохранением в localStorage.

## ✨ Возможности

- ✅ **Создание задач** — быстро добавляй новые дела
- ✔️ **Отметка выполненных** — отмечай то, что сделано
- 🗑️ **Удаление задач** — удаляй ненужные задачи
- 💾 **Сохранение данных** — все задачи сохраняются даже после обновления страницы
- 🎨 **Красивый дизайн** — современный градиент и плавные анимации
- 📊 **Статистика** — видишь сколько задач всего и сколько выполнено
- 🔍 **Фильтры** — показывай все задачи, только активные или только выполненные
- 🧹 **Очистка** — удаляй все выполненные задачи одной кнопкой
- 📱 **Адаптивный дизайн** — работает на телефоне, планшете и ПК

## 🚀 Быстрый старт

1. Скачай или склонируй репозиторий:
```bash
git clone https://github.com/artemka87/todo-list.git
cd todo-list
```

2. Открой `index.html` в браузере:
```bash
# На Windows
start index.html

# На macOS
open index.html

# На Linux
xdg-open index.html
```

Или просто откройте файл через File → Open файл в браузере.

## 💡 Как использовать

1. **Добавить задачу**: введи текст в поле и нажми кнопку `+` или Enter
2. **Отметить выполненной**: нажми на галочку рядом с задачей
3. **Удалить задачу**: наведи на задачу и нажми значок корзины
4. **Фильтровать**: используй кнопки «Все», «Активные», «Выполненные»
5. **Очистить выполненные**: нажми кнопку внизу, чтобы удалить все готовые задачи

## 📝 Как работает сохранение?

Все задачи сохраняются в localStorage браузера. Это означает:
- ✅ Задачи остаются даже если закрыть и открыть страницу
- ✅ Данные хранятся локально (ничего не передаётся на сервер)
- ⚠️ Если очистить данные браузера, задачи удалятся

## 🔒 Безопасность

- Текст задач экранируется (escapeHtml) для предотвращения XSS-атак
- Нет отправки данных на внешние серверы
