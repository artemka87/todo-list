# Tasks — Современный список задач

Минималистичное веб-приложение для управления задачами с чистым современным дизайном. Работает полностью в браузере с автоматическим сохранением.

## ✨ Возможности

- ✅ **Создание задач** — быстро добавляй дела в список
- ✔️ **Отметка выполненных** — отмечай готовые задачи
- 🗑️ **Удаление** — удаляй ненужные задачи со свайпом
- 💾 **Автосохранение** — все данные хранятся в localStorage браузера
- 🎯 **Фильтры** — переключайся между всеми, активными и выполненными
- 📊 **Статистика в реальном времени** — видишь все метрики на боковой панели
- 🌐 **Адаптивный дизайн** — работает идеально на любом устройстве

## 🎨 Дизайн

- Современный минималистичный интерфейс
- Светлая палитра с синими акцентами
- Плавные анимации и переходы
- Встроенные SVG-иконки (без зависимостей)
- Удобная боковая панель с фильтрами и статистикой

## 🚀 Быстрый старт

```bash
git clone https://github.com/artemka87/todo-list.git
cd todo-list
```

Открой `index.html` в браузере — и всё готово!

## 🎯 Как использовать

1. **Добавить задачу**: введи текст и нажми `+` или Enter
2. **Выполнить**: кликни на галочку рядом с задачей
3. **Удалить**: наведи и нажми иконку корзины
4. **Фильтровать**: используй кнопки на боковой панели
5. **Очистить**: нажми кнопку внизу, чтобы удалить все готовые

## 🛠️ Технологии

- **HTML5** — семантическая разметка
- **CSS3** — переменные, flexbox, grid, медиа-запросы
- **JavaScript (Vanilla)** — чистый код без библиотек
- **localStorage** — сохранение на клиенте
- **SVG** — встроенные иконки

- Текст задач экранируется (escapeHtml) для защиты от XSS
- Данные не передаются на серверы
- Всё работает локально
